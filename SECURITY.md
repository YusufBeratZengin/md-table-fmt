# Security Policy

## Supported Versions

| Version | Supported |
| :------ | :-------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in `md-table-fmt`, please do not open a public issue.

Report security issues responsibly by contacting the maintainer via GitHub Security Advisories at:
https://github.com/YusufBeratZengin/md-table-fmt/security/advisories/new

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a minimal proof of concept
- Affected versions and environments

Reports are investigated promptly and fixes are coordinated before public disclosure.
